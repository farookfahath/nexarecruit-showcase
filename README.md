# NexaRecruit

A fictional UAE recruitment agency sales demo showing candidate, client, interview, and follow-up administration.

**Documentation-only portfolio showcase by Farook Fahath.**

## Features

- Candidate search/filter/sort, profiles, recruitment stages, notes, and follow-ups.
- Client positions and submissions, interview scheduling/rescheduling, and status updates.
- Document-status review, reports, CSV export, and workspace settings.
- Browser-local persistence, confirmed demo reset, and responsive desktop/mobile layouts.

## Technology

React, TypeScript, Vite, responsive CSS, browser localStorage.

## Current status

Implemented frontend sales demo using fictional records. No verified public hosted demo is available.

## Scope and limitations

No backend, authentication, payments, AI integration, or multi-user synchronization. Document statuses do not upload files; no emails or messages are sent. Interview times use UAE GST (UTC+4).
